# MEDEPH s.r.o. website

Prezentačný web pre kardiologickú a internú ambulanciu MEDEPH s.r.o. v Poliklinike Sabinov.

![Hero section](public/images/hero-screenshot.png)

## Tech stack

- Next.js 16
- React 19
- TypeScript
- CSS
- ESLint

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run test
npm run typecheck
npm run lint
npm run build
```
