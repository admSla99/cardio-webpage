# MEDEPH s.r.o. website

Presentation website for the MEDEPH s.r.o. cardiology and internal medicine outpatient clinic at Poliklinika Sabinov.

![Hero section](public/images/hero-screenshot.png)

## Tech stack

- Next.js 16
- React 19
- TypeScript
- CSS
- ESLint

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run test
npm run typecheck
npm run lint
npm run build
```
